# Systems and Services Laboratories

## Objectives

By the end of this curricular unit, each student should be able to:

1. Understand how communication between applications is performed (on the same computer or across multiple) using the Internet.
2. Be familiar with the main protocols and mechanisms for application communication, and acquire skills in their development.
3. Understand the underlying model of relational databases and how to use SQL to interact with them.
4. Understand how multimedia elements are represented in digital communications.
5. Evaluate the correct use of virtualization mechanisms or containers and know how to apply each.
6. Understand and implement a WEB service with data persistence.
7. Build and access web services over the Internet, integrating all previous knowledge.

## Learning Outcomes

- **Operating System Administration (Command Line):** Proficiently manage Linux and Windows systems using command-line interfaces, a fundamental skill for system interaction and automation.
- **Virtualization and Containerization for Deployment:** Effectively use virtual machines and containers to isolate and organize software execution environments, crucial for modern application deployment and management.
- **Collaborative Software Development:** Understand and apply code version control and collaboration tools, essential for teamwork and efficient software development workflows.
- **Web Application Development Fundamentals:** Develop basic web pages and simple web applications using essential web technologies, providing a foundation for creating web-based services.
- **Data Manipulation and Analysis:** Skillfully handle data in common formats and employ data analysis tools, enabling data-driven decision-making and application development.
- **Ethical and Professional IT Practices:** Understand and apply GDPR principles, intellectual property rights, and software licensing in an ethical and professional manner, ensuring the responsible use of technology.

## Requirements

As this is an introductory course, there are no rigid requirements; however, the following skills are recommended:

- **A general interest in software development and IT-related topics:** The course aims to provide skills to develop services and applications.
- **Basic computer literacy:** Familiarity with using computers, operating systems, and basic software applications would be beneficial.
- **Willingness to learn technical concepts and participate in practical activities:** The course involves both theoretical understanding and practical application through scripts and exercises.
- **Problem-solving aptitude:** Advanced exercises in the practical scripts will challenge students to think critically and apply their knowledge.

## Assessment

The course assessment structure is designed to promote the continuous practical application of the content covered throughout the semester. The assessment is organized into two main components:

* **Practical Projects (50%):** The practical assessment includes two projects, carried out in groups, representing 50% of the final grade (25% each). The projects are distributed throughout the semester and focus on different sets of syllabus content:
  - Project 1 (mid-semester): focused on the content of topics C1 to C3, with oral defense and demonstration.
* **Individual Exam (50%):** Assessment conducted during the exam period via a test that evaluates the general understanding of concepts covered throughout the curricular unit, ensuring students have an integrated view of the content, specifically regarding topics C1 to C6, aligning with all learning objectives (O1 to O7).

## Methodology

The practical classes will be divided into two parts: the first part will be expository, introducing the themes that will be deepened later. The second part will consist of "hands-on" practical activities with detailed guides that exemplify the configuration, operationalization, development, and functioning of the covered topics.

The practical guides will be organized by class sessions, each with clearly defined objectives. They will introduce students to the basic concepts necessary to configure systems and carry out the work, complemented by guided exercises. After these initial steps, the guides will include sections with advanced exercises, challenging students to explore more complex functionalities of the presented topics. 

The gradual and conscious resolution of these guides, together with active participation in practical classes, will allow students to develop the necessary skills to pass the curricular unit. Furthermore, a final project will be carried out that integrates and applies the skills acquired throughout the different guides developed during the course.
